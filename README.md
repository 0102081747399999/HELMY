# نظام حلمي سنترال وموبايل (POS & Telecom Hub) 📱⚡

نظام إدارة ونقاط بيع متكامل لمحل هواتف ومحفظة فودافون كاش وسنترال، مبني بأحدث معايير وتصميمات UI/UX، وباللغة العربية الكاملة (`dir="rtl"`). تم ربط كافة البيانات وقواعد البيانات مباشرة بسيرفر **Google Firebase Firestore** مع مزامنة لحظية ودعم العمل بدون إنترنت (Offline LocalStorage Fallback).

---

## 🚀 طرق تشغيل النظام

يمكنك تشغيل النظام بأي من الطرق البسيطة التالية:

1. **التشغيل المباشر الفوري:**
   - انقر نقراً مزدوجاً على ملف `index.html` أو `تشغيل التطبيق مباشرة.bat`.
   - يفتح التطبيق مباشرة في متصفحك (Google Chrome / Edge) دون الحاجة لتثبيت أي برامج!

2. **التشغيل عبر خادم محلي للشبكة (لربط عدة أجهزة كاشير في المحل):**
   - انقر نقراً مزدوجاً على ملف `تشغيل التطبيق عبر السيرفر المحلي.bat`.
   - سيقوم الخادم بالتشغيل على الرابط `http://localhost:3000`، كما سيعرض لك رقم الآي بي (IP) الخاص بالجهاز لتتمكن من فتحه من هواتف المحل أو أي أجهزة كمبيوتر أخرى متصلة بنفس شبكة الواي فاي.

## 🔥 إعدادات الفيربيز والمزامنة السحابية (Firebase Sync)

تم ربط التطبيق بمشروعك على Firebase:
- **Project ID:** `mnmn-daadf`
- **Firestore Collections:**
  - `products`: مخزون الشواحن، الهواتف، السماعات، والصبات.
  - `vodafone_lines`: بيانات وإعدادات ومتبقي السقف وأرصدة الـ 18 خط.
  - `vodafone_transactions`: سجل العمليات (إيداع / سحب / عمولات) لكل خط.
  - `sales_invoices`: فواتير المبيعات ونقاط البيع السريعة.
  - `cash_drawer`: رصيد درج النقدية والورديات اليومية.

> **حالة قاعدة البيانات البدائية:** النظام يبدأ فارغاً تماماً **(0 أصناف / 0 بيانات وهمية)** مع واجهات فارغة أنيقة وأزرار سريعة للإضافة لتبدأ بإدخال بياناتك الفعلية.

## 📑 أقسام وصفحات النظام الستة (Core Navigation)

### 1. لوحة الإدارة والمؤشرات (لوحة التحكم الرئيسية):
- مؤشرات لحظية مجمعة: نقدية الدرج، إجمالي رصيد الـ 18 خط فودافون كاش، إجمالي مبيعات اليوم، النواقص الحرجة.
- مسح باركود مباشر وسريع.
- سجل أحدث فواتير المبيعات وأحدث معاملات الكاش مع إمكانية طباعة الإيصالات.

### 2. محافظ فودافون كاش (18 خط مستقل بالكامل):
- مصفوفة تفاعلية للـ 18 خط (من خط 1 حتى خط 18).
- شاشة كونسول خاصة لكل خط تعرض:
  - رقم التليفون والسقف الشهري والحد المتبقي والرصيد الحالي.
  - نموذج تسجيل: **إيداع / استلام كاش (+)** أو **تحويل / سحب كاش (-)** مع حساب العمولة الفورية تلقائياً وتحديث درج النقدية.
  - سجل حركات تفصيلي لكل خط مع إمكانية **تعديل** أو **حذف** أي حركة مع إعادة احتساب الرصيد تلقائياً.
  - زر **ضبط إعدادات الخط** لتعديل رقم الهاتف والسقف الشهري.
  - زر **تصفير الخط (Reset)** لإعادة تعيين الخط عند الحاجة.

### 3. قسم الشواحن والوصلات (5 تصنيفات فرعية):
- شاحن كامل (Complete Charger)
- رأس شاحن (Adapter/Head)
- وصلة شاحن عريضة (Type-C)
- وصلة شاحن عادية (Micro-USB)
- وصلة شاحن رفيعة (Pin / Lightning)
- إمكانية الإضافة بالباركود، تتبع المخزون وسعر التكلفة وسعر البيع وأزرار تعديل وحذف وزيادة/إنقاص سريع.

### 4. مبيعات التليفونات (IMEI):
- تسجيل الهواتف برقم الـ IMEI والسيريال، الماركة (Apple, Samsung, Xiaomi, Realme, Oppo, Infinix...)، الموديل، المساحة، واللون.
- تتبع حالة الجهاز (متوفر بالمحل / تم البيع).
- بيع مباشر من الجدول بنقرة واحدة أو عبر شاشة الـ POS.

### 5. قسم السماعات والصوتيات (3 فئات):
- سماعة جلدة (In-Ear)
- سماعة عضم (Classic / Hard-Shell)
- سماعة بلوتوث (Bluetooth Wireless)

### 6. قسم الصبات والمكبرات (3 أحجام):
- صب صغير (Small Speaker)
- صب وسط (Medium Speaker)
- صب كبير (Large Speaker)

## ⚡ قارئ الباركود ونقطة البيع السريعة (POS Cart)

- **قارئ الباركود العالمي:** يلتقط قارئ الباركود الموصل عبر الـ USB تلقائياً في أي شاشة.
- **إضافة صنف بالباركود:** مسح أي باركود غير مسجل يفتح نافذة الإضافة المباشرة والباركود معبأ مسبقاً.
- **نقطة البيع السريعة (F2):**
  - درج جانبي سريع يفتح بضغطة واحدة أو بالزر `F2`.
  - بمجرد مسح الباركود يُضاف الصنف فوراً إلى الفاتورة، مع إمكانية تحديد الخصم وحساب الباقي للعميل.
  - عند إتمام البيع: يتم خصم الكمية من المخزون في الفيربيز تلقائياً، وتسجيل النقدية في الدرج، وفتح نافذة **طباعة الإيصال الحراري (Thermal Receipt 80mm)**.

---

## ⌨️ اختصارات لوحة المفاتيح السريعة

- `F1`: إضافة صنف جديد للمخزن.
- `F2`: فتح نقطة البيع السريعة (POS Cart).
- `F4`: الانتقال السريع لمحافظ فودافون كاش.
- `ESC`: إغلاق أي نافذة منبثقة أو سلة البيع.
