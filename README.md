# نظام سنترال حلمي وموبايل (Central Hilmy POS & Telecom Hub) 💻📱⚡

نظام إدارة ونقاط بيع متكامل لمحل **سنترال حلمي وموبايل** لإدارة محافظ فودافون كاش الـ 18، ومخازن ومبيعات الهواتف والشواحن والوصلات والسماعات والصبات والجرابات والإكسسوارات، مع دعم العمل على الكمبيوتر واللاب توب والهاتف المحمول.

---

## 🌟 التحديثات والمميزات الجديدة (v2.0):

### 1. هوية المحل: "سنترال حلمي وموبايل"
- اعتماد اسم **"سنترال حلمي"** رسمياً في جميع شاشات النظام، الهيدر، الفواتير، الإيصالات، والبانر الرئيسي.

### 2. نظام الكود الذكي الموحد: كتابة يدوية + مسح باركود (بيع أم تسجيل)
- **شريط الكود السريع الذكي:** متوفر دائماً في أعلى الشاشة الرئيسية وعلى الموبايل لكتابة أي كود صنف (مثل: `70`) يدوياً أو مسحه بمسدس الباركود أو الكاميرا.
- **نافذة الإجراء التفاعلية التلقائية:**
  - عند كتابة الكود والضغط على Enter أو مسحه:
    - **إذا كان الصنف مسجلاً مسبقاً:** تظهر نافذة ذكية تسألك فوراً: **"هل تريد بيع أم تسجيل (توريد للمخزن)؟"**
      - **خيار [ 💰 بيع الصنف ]:**
        - تحدد الكمية وسعر البيع واسم العميل.
        - ينقص الصنف من المخزن فورياً.
        - **ينزل تلقائياً في [صفحة سجل مبيعات القسم] مع التاريخ والوقت بالدقيقة والربح المحقق!**
        - تضاف النقدية في درج الكاشير.
      - **خيار [ 📦 تسجيل وتوريد للمخزون ]:**
        - تحدد الكمية المضافة وتاريخ التوريد وتعديل الأسعار إن وجد.
        - تزيد الكمية فوراً في صفحة المخزون ويتم تحديث تاريخ آخر توريد.
    - **إذا كان الكود جديداً (غير مسجل):** تفتح نافذة التسجيل والكود معبأ مسبقاً، لتختار القسم وتدخل بيانات الصنف ليتم حفظه بالكود والتاريخ فوراً.

### 3. نظام الصفحتين لكل قسم: [صفحة المخزون] + [صفحة المبيعات] مع التواريخ
لكل قسم من الأقسام التالية يوجد تبويبين منفصلين:
1. **السماعات والصوتيات** (Headphones)
2. **الشواحن ورؤوس الشحن** (Chargers)
3. **وصلات الشحن والكابلات** (Cables)
4. **الصبات ومكبرات الصوت** (Speakers)
5. **التليفونات والهواتف الذكية** (Phones)
6. **جرابات الهواتف والحمايات** (Covers) — *قسم جديد تماماً*
7. **الإكسسوارات العامة** (Accessories)

- **صفحة المخزون (Inventory):**
  - جدول الأصناف المتوفرة، الكود، الاسم، النوع، سعر الشراء، سعر البيع، الكمية بالمخزن، **تاريخ التوريد والإضافة الدقيق بالعربية**.
  - أزرار سريعة بنقرة واحدة: `[💰 بيع]` و `[📦 توريد]`.
  - إحصائيات: إجمالي القطع، تكلفة الشراء، القيمة البيعية، الأرباح المتوقعة.
- **صفحة سجل المبيعات (Sales Log):**
  - جدول مبيعات هذا القسم تحديداً.
  - يسجل تلقائياً: **تاريخ ووقت البيع بالدقيقة**، كود الصنف، اسم الصنف، الكمية المباعة، سعر البيع، الإجمالي، **وصافي الربح المحقق (باللون الأخضر)**، والعميل.
  - إحصائيات: إجمالي مبيعات القسم، صافي الأرباح المحققة، عدد عمليات البيع.

### 4. محافظ فودافون كاش الـ 18 خط (مفيش فيها فلوس - رصيد 0.00 ج.م)
- جميع الخطوط الـ 18 تبدأ بأرصدة `0.00 ج.م` بدون أي بيانات وهمية.
- زر **[ 🔄 تصفير جميع الخطوط (0 ج.م) ]** بنقرة واحدة عند الرغبة.
- لكل خط كونسول مستقل لتسجيل عمليات الإيداع (+) والسحب (-) والعمولات والسقف الشهري.

### 5. ربط أرقام الهواتف واستقبال رسائل الكاش تلقائياً (SMS Auto-Sync)
- **الربط التلقائي عبر Webhook:**
  - يدعم استقبال إشعارات الرسائل من أي تطبيق تحويل SMS على هواتف الأندرويد (مثل SMS Forwarder أو MacroDroid).
  - رابط الويب هوك: `http://<LOCAL_IP>:3000/api/sms-webhook`.
  - النظام يتعرف تلقائياً على: نوع الحركة (إيداع/سحب)، المبلغ، رقم العميل، الرصيد الجديد، ورقم الخط، ويحدث الرصيد تلقائياً ويسجل الحركة!
- **معالج ولصق رسائل الكاش الذكي (Instant SMS Parser):**
  - زر في أعلى الشاشة للصق أي رسالة فودافون كاش أو انستاباي يدوياً.
  - يحلل الرسالة فوراً ويستخرج المبلغ والعميل والرصيد والخط المتطابق، وزر بنقرة واحدة لاعتمادها وتحديث الرصيد فوراً.

### 6. تشغيل النظام على الهواتف المحمولة (100% Mobile Responsive)
- واجهة متجاوبة بالكامل مع شاشات الموبايل والتابلت.
- **شريط ملاحة سفلي للموبايل (Bottom Navigation Bar):** للوصول السريع بالإبهام للرئيسية، الـ 18 خط، كود سريع، الأقسام، والكاشير.
- **زر [ 📱 فتح على الموبايل ]:** يعرض الآي بي المحلي وكود QR يمكن مسحه بكاميرا أي هاتف على شبكة الواي فاي لفتح النظام في ثانية واحدة!

## 🚀 طرق تشغيل النظام

1. **التشغيل عبر السيرفر المحلي (موصى به لربط الهواتف والـ SMS):**
   - انقر نقراً مزدوجاً على ملف: `تشغيل التطبيق عبر السيرفر المحلي.bat`.
   - يفتح المتصفح تلقائياً على: `http://localhost:3000`.
   - يعرض لك رابط الموبايل وربط الرسائل (مثال: `http://192.168.1.7:3000`).

2. **التشغيل المباشر الفوري (بدون سيرفر):**
   - انقر نقراً مزدوجاً على ملف: `تشغيل التطبيق مباشرة.bat` أو افتح `index.html`.
